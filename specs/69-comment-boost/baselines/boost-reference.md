# Boost UI 唯一参照

来源：用户需求附件《Boost 评论 + 设置页复刻 Stellar 配置》的 Part A 已确认目标形态。

每条评论的 actions 行有一个火箭入口。点击后出现小面板，面板包含固定表情 `👍`、`❤️`、`😄`、`🎉`、`😕`、`🚀`，以及最多 16 个 Unicode 字符的可选短文本和发送动作。每个 Boost 以独立 chip 挂在评论正文下方，chip 依次展示发布者头像、表情和短文本。每楼最多 50 条；不能 Boost 自己的评论；发布者可以删除自己的 Boost。当前身份已经 Boost 时，火箭入口移动到 chip 条末尾；达到 50 条后隐藏火箭入口。

验收只对照以上形态和 `spec.md` 中的逐项清单，不引入 linux.do 之外的新视觉方向。
