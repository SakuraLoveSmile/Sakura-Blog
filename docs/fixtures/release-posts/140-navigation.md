## 一次完整的导航链路

首页卡片应能进入文章详情，详情页中的主题、分类和标签链接应分别进入对应列表。搜索结果、RSS 和站点地图也应该引用同一个 slug。

```text
首页 -> 文章详情 -> 标签归档 -> 相关文章 -> RSS
```

## 需要关注的边界

- slug 只包含稳定的 ASCII 字符。
- 摘要较长时，卡片高度仍然一致。
- 在 375px 宽度下，导航和文章元信息允许换行。

{% tip text:链接目标要可预测 %}
测试文章的 slug 使用 `140-` 前缀，方便在 Console、搜索和前台之间交叉核对。
{% endtip %}
