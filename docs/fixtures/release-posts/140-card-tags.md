## 标签是内容导航

当首页卡片开启标签时，读者不需要打开文章就能知道它属于哪些主题。标签文字应该保持紧凑，并且在窄屏上自然换行。

| 检查项 | 预期 |
| --- | --- |
| 标签显示 | 卡片底部显示全部标签 |
| 链接目标 | 点击进入对应标签归档 |
| 长标签 | 不遮挡标题和摘要 |

## 与分类的边界

分类适合表达稳定的栏目，标签适合表达跨栏目的主题。这个 fixture 同时设置 category、topic 和 tags，用来检查三者在列表与详情页的关系。

{% tip text:卡片标签是可配置能力 %}
打开 `article.card_tags` 后才显示卡片标签；关闭配置时，文章内容和详情页标签仍然可用。
{% endtip %}
