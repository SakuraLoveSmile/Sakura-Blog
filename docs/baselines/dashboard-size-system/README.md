# Dashboard Small / Medium / Large 验收边界

## 唯一参照

- 产品参照：用户批准的《仪表盘三级尺寸（Small / Medium / Large）组件设计优化调研与实施计划》
- 视觉规范：`resource/apple-design/` 的深色语义 token、Card 和 Button 组件模式
- 产品主题：Blog 永久深色模式；不验收浅色分支

## 可观察验收清单

- [ ] 电脑断点使用 12 列网格，组件没有越出网格容器或产生非规范列宽
- [ ] 平板断点使用 6 列网格，组件位置和宽度均保持在容器内
- [ ] 手机断点使用 4 列网格，组件不发生横向裁切
- [ ] 尺寸弹窗展示比例预览、内容密度说明和实际网格规格
- [ ] 同一断点下相同实际列跨度只显示一个预设代表，且只出现一个高亮状态
- [ ] Small / Medium / Large 的统计、趋势、时段、分类、文章、评论、快捷操作和版本组件均有可观察的内容差异
- [ ] 修改尺寸后组件仍能拖动、移除、保存布局并重新加载
