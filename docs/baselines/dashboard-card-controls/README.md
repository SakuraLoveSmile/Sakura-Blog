## 取证数据与布局

e2e 夹具库（`scripts/e2e/prepare.go`）建一个空站点，仪表盘默认布局里没有「大档」的最近文章 / 最近评论，也没有趋势中档，而行操作、内联评论操作、弹窗、UV 开关只在这些档位渲染。取证脚本和 e2e 用例因此先用 `PUT /api/v1/dashboard/layout` 摆出下面这组布局（桌面、平板、手机各一份），再灌数据：

- 趋势：中档与大档各一张（中档有 UV 开关，大档的 PV / UV 是静态图例）；
- 访问时段、热门文章：中档各一张；
- 最近文章：小、中、大三档（大档有行操作，小档是 107px 高的盒子，头里也有「全部 ›」）；
- 最近评论：小、中、大三档（大档有内联操作与弹窗）；
- 最近说说（没有档位，取决于 moments 模块是否启用）。

数据：8 篇文章（7 篇已发布、1 篇草稿，slug `card-controls-1..8`）、每篇已发布文章访问若干次产生 PV / UV；9 条评论（昵称「验收访客 N」，内容含「夹具评论」，最新两条置为待审）。`tests/e2e/dashboard-card-controls.spec.ts` 在 `afterAll` 里还原默认布局并删掉这些文章与评论，不留给后面共用同一个服务的用例。

### 手机（视口 390×844 触屏，自适应，`data-bp=xxs`，真实 ≤767px）

## 已知例外

- **小档（107px 高）卡片头的「全部 ›」只有约 35px**（最近文章、最近评论小档，所有手机场景一致）：它的下方紧邻第一行迷你列表，点击区补到邻居为止、不抢点击，所以只能补到 35px；再多补就要改小档盒子（三档盒子高度是定的）。
- **手机最近评论大档的「全部 ›」有时约 43px**：第一行的操作栏紧贴在它下面时（取决于第一行内容怎么折行；取证里出现、探针里没有），点击区被「标记垃圾」按钮截断，差 1px（`blocked`，不是 `uncovered`，也不抢邻居的点击）。
- **整行宽度的行级按钮改前就不足 44px，本任务没有动**：最近文章大档的 `recent-post-main`（41px 高）、迷你列表的 `recent-mini-row`（28 / 42px 高）。`measureTouchTargets` 会把它们记为 `uncovered`，e2e 用例按名称过滤。
- **真机视口 390 + 「电脑」预览**（画布 1440px 宽、可横向滚动，是手机上主动选了电脑布局的情形；手机默认布局不受影响）：`measureTouchTargets` 把控件滚到视口边缘后量不到外侧，会报出一批 `uncovered` / `blocked`（探针已确认采样点落在视口外），这个场景改用计算样式核对每个控件的 `::before` 点击区（`X1`）。其中有一处是真实的邻居限制：趋势中档的「7 天」夹在 UV 与「30 天」之间（只隔 16px），UV 的盒子压在它上面（`z-index: 1`），所以「7 天」的点击区宽只有约 32px。

## 未验证项

- 没有真机、Safari、Firefox 与屏幕阅读器的验证：全部在系统 Chrome 的 Playwright 里完成（桌面 1440、触屏仿真 390 / 375 / 360、桌面预览平板与手机）。触屏是 Chrome 的 `isMobile` + `hasTouch` 仿真，不等于真实手指的落点与滑动手势。
- 新 e2e 只在一次性私有配置上跑过（`workers: 1`、系统 Chrome、`:8108`、生产构建），**没有走仓库自带的 `playwright.config.ts`**（它固定 `:8096`、`VITE_E2E=1` 构建与 `webServer`；8096 是各工作树 e2e 共用的端口，这次没有占用）。已核对的等价条件：两份配置都是 `fullyParallel: false`、`workers: 1`，`beforeAll` 灌数据 / `afterAll` 清理不会被并发打架；`VITE_E2E` 只影响富文本编辑器的测试钩子，不影响仪表盘。但整包 `pnpm run e2e` 里它与其它用例共用同一个服务与数据库的情形没有实跑过。
- 没有深色以外的主题验证（仪表盘当前只有 Direction A 深色）。
- 叠放容器（C6）不在本任务。

## 复现

先用 `make build` 构建，再用隔离端口启动测试服务（不要用 e2e 默认的 8096，也不要占用其它工作树的端口）：

```bash
E2E_LISTEN=:8108 bash scripts/e2e/run-server.sh
```

然后用一次性配置（`.tmp` 不入库，参考仓库 `playwright.config.ts`，把 `baseURL` 指向该端口、去掉 `webServer`）运行：

```bash
pnpm exec playwright test tests/e2e/dashboard-card-controls.spec.ts
```

`dashboard-card-controls.spec.ts` 在 `beforeAll` 里灌数据、摆布局，在 `afterAll` 里清理；`tests/e2e/support/dashboard-cards.ts` 同时是改前 / 改后取证脚本的量测代码。
