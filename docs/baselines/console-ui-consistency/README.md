# Console UI 一致性设计参照基准 (Design Reference)

本基线记录《Console UI 一致性修复计划》的固定设计裁决、视觉参照图与验收边界。

## 1. 唯一参照图

- **设计基线路径**：`docs/baselines/console-ui-consistency/design-reference.png`
- **涵盖区域**：
  1. **桌面列表与卡片**：1400px 内容容器、标题 24px/600、副标题 13px、胶囊主按钮（黑色文字高对比无辉光）、紧凑 80px 概览卡片（蓝/中性身份色区分）。
  2. **手机操作区与底栏**：390px 视口、三行自适应排列（1. 标题区；2. 搜索框整行；3. 按钮组整行可换行）、44px 最小触控区域、底栏包含完整 5 项真实 Remix Icon。
  3. **设置分区与 Tabs**：1100px 容器、`VTabbar(type="segmented")` 顶部单行滑动、单一卡片边界、无内外重复卡片与标题。
  4. **弹窗与控件阶梯**：标准模态弹窗、2px 焦点环 (`:focus-visible` / offset 2px)、按钮尺寸阶梯 (xs 24 / sm 28 / md 36 / lg 40px)。

## 2. 精确色彩对比度与固定规范 (WCAG 2.1 AA)

| 场景 / 元素 | 颜色组合 | 精确对比度 | WCAG 评定与规则 |
|---|---|---|---|
| 主操作按钮 (Primary) | `#000000` on `#2e8dff` | **6.37:1** | 合格 (≥4.5:1 AA)。胶囊圆角，无外发光，字距为 0 |
| 危险操作按钮 (Danger) | `#000000` on `#ff453a` | **6.16:1** | 合格 (采用黑字达标)。**严禁用白字**（白字 `#ffffff` on `#ff453a` 仅 3.41:1 不达标） |
| 次要操作按钮 (Secondary) | `#f5f5f7` on `#2c2c2e` | **12.6:1** | 合格 (极佳对比度)。1px 边框 `#3a3a3c` |
| 状态语义色 | 成功绿 `#30d158`、警告橙 `#ff9f0a`、错误红 `#ff453a` | - | 管理员蓝色、作者中性色，红色仅表达错误或危险 |

## 3. 固定尺寸、布局与触控规则

| 项目 | 固定规则 |
|---|---|
| 页面背景与卡片 | 背景 `#000000`；卡片 `#1c1c1e`，边框 `1px solid #3a3a3c`，radius-xl (16px)；工具栏 radius-lg (12px) |
| 按钮 | 保持已实现的胶囊圆角及桌面 24/28/36/40px 高度；文字字距为 0 |
| 手机触控 | `<768px`：单行输入、搜索、选择器、筛选按钮高度至少 **44px**；独立图标按钮至少 **44×44px** |
| 焦点 | 2px ring、2px offset (`:focus-visible`)；实际键盘聚焦可见，无布局跳动 |
| 内容边距 | `<768px` 为 16px，768–1023px 为 24px，`≥1024px` 为 32px |
| 标题 | 页面标题手机 20px、桌面 24px，字重 600；分区标题 16px/600 |
| 概览卡片 | 左图标、右侧标签/数值/说明；桌面最小 80px，手机最小 88px；手机两列、`≥1024px` 四列；消除高度跳动 |
| 卡片层级 | 普通卡片 radius-xl、1px 边框；同一设置分区只保留一个卡片边界，消除内外卡片重叠 |
| 装饰与动效 | 普通卡片不发光、不自动抬升；浮层保留必要阴影；图表系列色不改；减少动态效果模式下关闭非必要位移 |
| 手机三行布局 | 标题操作区在 `<1024px` 严格按「1. 标题区 → 2. 搜索框整行 → 3. 操作按钮组整行」排列；底部预留安全区（无遮挡） |
