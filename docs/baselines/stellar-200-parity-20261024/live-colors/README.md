唯一颜色参照为 `reference-dark.jpg`，真实线上现状为 `before-live-dark.jpg`，原始计算值在 `comparison-before.json`。前轮已对齐的 8124 隔离样例与此线上博客是两个运行对象，不能将样例结果视为线上结果。

用户明确选择“应用到线上博客”后，已通过现有已认证 Console 校验并保存。`proposed-appearance.json` 是约定的五个目标字段，不是可以直接覆盖完整站点设置的请求体。保存前备份现有文档、深合并指定字段，保存后重新读取整份 JSON 与候选完全一致；其他配置和敏感字段遮罩保持。结果见 `applied-appearance.json`。

调整后实测：

- `browser-verification.json` 的浅/深色 × 1280/390px 共 4 组，body 背景及背景、卡片、主题、强调、链接、文字 token 与参照相同。颜色比较仅规范化空格、deg 和三位十六进制表示。
- 文章、搜索各覆盖浅/深色与桌面/手机，共 8 组，均无页面横向溢出。真实搜索“Hexo”各返回 3 个结果，并实际关闭搜索、打开真实公开文章。
- 手机为 390×844 CSS 视口模拟，使用 CDP 控制后读取真实页面并操作 UI。原生手机截图缩放不可靠，本轮不将这类图作为证据；只保存可靠桌面截图，测量中写明实际视口。
- `public-http-verification.json` 使用未登录请求确认首页加载 minimal，样式实际字节与本地锁定产物一致，readyz 正常。没有替换线上镜像或二进制。
- `restored-browser-state.json` 确认模拟已清除，auto 跟随系统且无访客 data-theme 覆盖。只保留线上公开首页体验标签页。

`after-live-{dark,light}-desktop.jpg` 为实际线上首页；文章、搜索桌面图是补充。独立菜单 accent、分类色和字体继续使用本站原有配置，左栏博客图标仍可见青色，因此这里只确认已约定的全局配色一致，不声称整个网页复制了作者站。
