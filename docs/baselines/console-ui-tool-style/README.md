# Console UI 朴素工具型设计基准 (Design Reference)

本基线记录《Console UI 去“AI 味”重做（朴素工具型）》的唯一设计参照图、材质裁决、尺寸阶梯与验收对比清单。

## 1. 唯一设计参照图

- **设计基线路径**：`docs/baselines/console-ui-tool-style/design-reference.png`
- **涵盖核心区域**：
  1. **桌面列表与卡片**：1440px 视口，实色 `#1c1c1e` 卡片，1px `#3a3a3c` 边框，无阴影，无顶部高光亮线。高密度 44px 列表行高，行内编辑/删除操作常显，胶囊主按钮黑字高对比。
  2. **手机操作区与底栏**：390px 视口，实色底栏与抽屉，触控保证 ≥ 44px，操作无遮挡。
  3. **设置分区与 Tabs**：单层卡片边界，分段式 Tabs，8px 输入控件阶梯，消除多层重复嵌套边框。
  4. **弹窗与控件阶梯**：14px 模态弹窗圆角（`xl`），8px 输入控件（`sm`），10px 面板卡片（`md`），全胶囊按钮（`full`），2px `:focus-visible` 焦点环。
  5. **仪表盘**：KPI 数值 24px/600 `tabular-nums`，中性卡片底，图表仅使用 `--color-chart-1..5`，无装饰性浮夸光晕与毛玻璃。

## 2. 视觉材质与参数阶梯规范

| 属性 | 规范值 | 说明 |
|---|---|---|
| 全局背景色 | `#000000` | 纯黑实色，无背景光晕与径向渐变 |
| 面板与卡片底色 | `#1c1c1e` (`--color-card`) | 实色，消除 `backdrop-filter` 毛玻璃与顶部 1px 亮线 |
| 边框 | `1px solid #3a3a3c` (`--color-border`) | 面板、分割线与控件统一边框 |
| 阴影策略 | 常驻面板 `none`；仅浮层使用 `--shadow-*` | 仅下拉、弹窗、抽屉、toast、操作坞保留阴影 |
| 圆角阶梯 | `sm` 8px / `md` 10px / `lg` 12px / `xl` 14px / `2xl` 16px / `full` 9999px | 输入框 8px，卡片 10px，弹窗 14px，按钮/开关 胶囊 |
| 侧边栏 | `#1c1c1e` 实色 + 1px 右边框 | 图标 24px，消除 3px 悬浮光环与 "Powered by" 署名 |
| 按钮体系 | `VButton` 维持胶囊、36px 高度、黑字 on 主色 | Primary `#000000` on `#2e8dff`，对比度 6.37:1 |
| KPI 排版 | 24px, 600 weight, `tabular-nums` | 数字等宽对齐，消除大写英文眉标与 emoji |
| 动效克制 | 禁用 `.hover-lift`，禁用 `transition: all` | 仅保留必要状态过渡，无呼吸灯与常驻位移 |

## 3. WCAG 2.1 AA 对比度保障

| 元素 | 色彩搭配 | 对比度 | 结论 |
|---|---|---|---|
| Primary 按钮 | `#000000` on `#2e8dff` | **6.37:1** | 合格（≥4.5:1 AA），无外发光 |
| Danger 按钮 | `#000000` on `#ff453a` | **6.16:1** | 合格（≥4.5:1 AA），禁止白字 |
| Secondary 按钮 | `#f5f5f7` on `#2c2c2e` | **12.6:1** | 极佳 |
| 正文文本 | `#f5f5f7` on `#1c1c1e` | **14.2:1** | 极佳 |
| 次级说明文本 | `#8e8e93` on `#1c1c1e` | **4.68:1** | 合格（≥4.5:1 AA） |
